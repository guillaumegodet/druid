L'onglet **Collaborations** montre avec qui la structure publie : les autres laboratoires de
l'établissement, les institutions françaises, les partenaires étrangers, et les alliances
d'universités. Il se lit sur la période et le périmètre choisis en haut du tableau de bord.

## Les sous-onglets

| Sous-onglet | Ce qu'il montre |
|---|---|
| **Typologie** | La part de chaque type de collaboration et son évolution annuelle. |
| **Dans la structure** | Pour une structure composite : les copublications entre ses laboratoires internes. |
| **(nom de votre établissement)** | Les autres laboratoires de l'établissement les plus cosignataires, et les thématiques partagées. |
| **Nationales** | Les institutions françaises (hors établissement) les plus cosignataires. |
| **Internationales** | Les pays et les organismes étrangers : carte, classement, évolution, flux. |
| **Par pays** | La collaboration avec **un** pays partenaire : ses établissements, les labos et chercheurs impliqués, les thématiques, l'impact, les financeurs. |
| **Institutions partenaires** | Le bilan des copublications avec une institution ou un groupe d'institutions choisi. |

Les types de collaboration sont définis dans
[Publications et attribution](/donnees/publications-attribution/#collaborations). Une
publication peut en cumuler plusieurs ; la **Typologie** retient pour chacune la catégorie
la plus large.

## Faire le bilan avec un pays

1. Ouvrez le sous-onglet **Par pays**.
2. Choisissez le **Pays partenaire** : les pays sont classés par ordre alphabétique, avec leur
   nombre de copublications sur la période ; tapez quelques lettres pour filtrer la liste
   (accents ignorés, nom français ou anglais : « vietnam » trouve le Viêt Nam).
3. Si besoin, cochez :
   - **Exclure les grandes collaborations (> 50 auteurs)** pour écarter partout les
     publications de grands consortiums ;
   - **Regrouper hôpitaux et instituts avec leur université** pour compter, par exemple, un
     institut de cardiologie avec l'université dont il dépend.
4. Lisez les blocs, de haut en bas :
   - **chiffres clés** : copublications, part des copublications internationales, rang du pays
     parmi les pays partenaires, tendance, part de copublications **bilatérales** (sans autre
     pays étranger), chercheurs et labos impliqués, accès ouvert, grandes collaborations ;
   - **évolution** par année et **rang** du pays parmi les pays partenaires ;
   - **établissements du pays** : carte, classement et, quand l'export les connaît,
     répartition par **province, État ou région** ;
   - **labos et chercheurs impliqués**, et **Qui travaille avec qui** : les principaux labos
     croisés avec les principaux établissements du pays ;
   - **thématiques** : domaines, sous-disciplines et **spécialisation** (voir plus bas) ;
   - **impact**, comparé à une référence comparable ;
   - **financements** : les financeurs remerciés, selon qu'ils sont du pays, européens,
     français ou d'ailleurs ;
   - **autres pays et langues** : part bilatérale, autres pays des copublications
     multilatérales, langues.
5. Cliquez sur un établissement, un chercheur, une case du tableau croisé, un financeur ou une
   sous-discipline pour ouvrir les publications correspondantes ; **Voir les N publications**
   ouvre toute la liste.

Le lien de la page garde le pays et les options cochées : vous pouvez le partager tel quel.
Chaque graphique peut aussi être **ajouté à un rapport** avec son pays ; pour un rapport
complet, utilisez le modèle
[Collaboration avec un pays](/guides/rapports/modeles/#collaboration-avec-un-pays).

### Lire la spécialisation

L'indice de **spécialisation** compare le poids d'une sous-discipline dans les copublications
avec le pays à son poids dans **l'ensemble** des copublications internationales de la
structure. Au-dessus de 1, la sous-discipline est plus présente avec ce pays qu'avec les
autres ; en dessous, moins. Seules les sous-disciplines assez fréquentes sont retenues
(20 copublications, 5 pour un petit corpus).

### Lire l'impact

L'impact des copublications (FWCI médian, part dans le top 10 %) est comparé aux **autres**
copublications internationales de la structure dans les mêmes sous-disciplines, pondérées
comme les copublications avec le pays. Les publications de plus de 50 auteurs en sont
toujours écartées.

## Faire le bilan avec une institution ou une alliance

1. Ouvrez le sous-onglet **Institutions partenaires**.
2. Choisissez un **groupe prédéfini** (par exemple une alliance d'universités européennes
   comme EUniWell), ou cherchez une institution partenaire par son nom. Vous pouvez en
   ajouter plusieurs pour composer votre propre groupe.
3. Lisez le bilan : nombre de copublications, évolution annuelle, domaines et
   sous-disciplines, chercheurs de l'établissement les plus impliqués.
4. Pour un groupe d'universités, **Par université** détaille les copublications avec chaque
   membre ; cliquez sur une barre pour voir les publications.
5. Cochez **Exclure les grandes collaborations** pour écarter les publications à très
   nombreux auteurs (physique des particules, grands consortiums), qui gonflent les chiffres.

### Analyse thématique

Sur certaines instances, **Analyse thématique (IA)** vous permet de décrire une thématique
(« décarbonation maritime », « IA et santé »…) : l'assistant propose les sujets
correspondants parmi ceux réellement présents dans les copublications. Corrigez la liste,
puis **Générer l'analyse**.

## Ce qui se passe ensuite

Rien n'est modifié. Chaque graphique peut être exporté ou partagé (voir
[Exporter](/guides/tableau-de-bord/exporter/)), et les publications détaillées ouvertes dans
la liste.

## Limites connues

- **Une publication cosignée par plusieurs partenaires compte pour chacun** : la somme des
  barres dépasse le total des copublications.
- **Les institutions viennent d'OpenAlex** : une affiliation mal reconnue fait disparaître
  (ou apparaître à tort) un partenaire.
- **Les co-affiliations d'un même auteur** (un chercheur rattaché à l'université et au CNRS)
  ne sont pas comptées comme des collaborations.
- **L'analyse thématique** est une aide : les sujets proposés sont à vérifier.
- **Par pays** : une publication est rattachée au pays quand un de ses auteurs est affilié à un
  établissement de ce pays. Les noms de provinces et de régions sont ceux d'OpenAlex, en
  anglais. Pour l'export d'un établissement, cliquer sur un labo n'ouvre pas la liste (les labos
  y sont portés par les auteurs, pas par les publications).
- **Les financeurs sont ceux que les publications remercient** : ils ne disent ni qui a payé la
  recherche ni qui porte le financement. La Commission européenne n'a pas de pays : elle est
  classée « Europe ».
